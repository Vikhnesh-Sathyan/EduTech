Required CSV Columns

Your CSV file must contain these column names:

question_text option_a option_b option_c correct_option

• Each question must contain exactly three options.

• Correct option must be A, B or C.

• Questions will automatically belong to the selected subject.

• Duplicate questions inside the CSV are not allowed.

• All rows must be valid before importing.

CSV Example

question_text,option_a,option_b,option_c,correct_option
What is Angular?,Framework,Database,Operating System,A
What is a component?,UI building block,Database table,Server,A
Which language does Angular use?,JavaScript,Python,C++,A
